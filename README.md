# Cherry Spot — Releases

This repository holds the compiled, installable builds of **Cherry Spot**.

Grab the latest installer from the [Releases](../../releases) page:

- **`.exe`** — recommended installer (NSIS)
- **`.msi`** — alternative Windows installer

The app updates itself automatically once installed — you only need to download
manually this one time. Every release after your current version will offer an
in-app "Update & Restart" prompt.

> Source code lives in a separate private repository. This repo only ever
> contains released binaries.
